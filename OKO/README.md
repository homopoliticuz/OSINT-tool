# ОКО — мониторинг аналитических источников

**ОКО** — персональная платформа аналитика. Она ищет всё, что мировые аналитические центры, международные организации, официальные источники, авторитетные издания и соцсети публикуют об **Узбекистане**, а также по любой другой теме, людям и организациям, за точно заданный период.

- **Один запрос — 12+ языков.** Слово «Узбекистан» автоматически превращается в *Uzbekistan, Ouzbékistan, Usbekistan, Uzbekistán, 우즈베키스탄, ウズベキスタン, 乌兹别克斯坦 / 烏茲別克, ازبکستان, أوزبكستان*, в турецкий и узбекский варианты. Добавляются связанные термины: столица, глава государства, крупные города. Все термины можно посмотреть и исправить.
- **Все страны мира.** Google News по изданиям ~20 стран, GDELT (мировые СМИ на 65 языках), Bing News, адресный поиск по сайтам аналитических центров, их RSS-ленты и внутренний поиск по сайтам.
- **Реестр из 818 источников.** Все аналитические центры и издания из вашего раздела закладок «Аналитика», международные организации — авторы глобальных докладов и индексов, официальные источники, агентства, издания по Центральной Азии. Полный список — в [SOURCES.md](SOURCES.md).
- **По какому слову найдено.** В карточке — исходное ключевое слово, сработавший термин (перевод, словоформа или связанный термин), где он найден и каким запросом. Термин подсвечен в заголовке.
- **Строго по теме.** Статьи, где тема упомянута вскользь (боковая колонка, «читайте также»), по умолчанию скрыты. ОКО само открывает сомнительные страницы, считает упоминания и возвращает в ленту те, где тема раскрыта; в карточке — цитата.
- **Уровень авторитетности** у каждого материала: **A** — высший, **B** — высокий, **C** — базовый, **D** — вне реестра.
- **Первоисточник или перепубликация** — ✔ / ⟳ / ? с обоснованием: «материал агентства Reuters», «canonical указывает на reuters.com», «пересланный пост из канала …».
- **Перевод на русский прямо в карточке:** заголовок, аннотация, полный текст статьи, PDF перевода.
- **Соцсети отдельной выдачей:** Telegram-каналы (без ключей), ВКонтакте, X, YouTube, публичные публикации LinkedIn, Facebook, Instagram и WhatsApp-каналы (по ключам API).
- **Мониторинг источников:** лента последних публикаций выбранных сайтов и Telegram-каналов с отметкой новых. Избранные материалы — в «Досье».
- **Доклады:** новые выпуски глобальных докладов и индексов (ООН, МВФ, Всемирный банк, ЕС, ОЭСР, ВОЗ, WEF, Global Peace Index, SIPRI, Freedom House, RIAC и др.) и календарь ожидаемых выпусков.
- **Персоны и OSINT:** профиль человека по Wikidata и его упоминания на всех языках; проверка e-mail, телефона, имени пользователя, домена, ссылки, IP по открытым данным.
- **PDF и архив:** страница оригинала, режим чтения, сводка по ленте, досье; веб-архив; библиографическая ссылка по ГОСТ.
- **С телефона:** Telegram-бот (поиск, сводки, ежедневный дайджест) или браузер телефона в домашней сети.

## Установка и запуск

Нужен только **Python 3.8 или новее**. Сторонние библиотеки не требуются.

| Система | Как запустить |
|---|---|
| **Windows** | Дважды щёлкните **`START_OKO.bat`**. Если Python не установлен, откроется python.org: установите, отметив *«Add python.exe to PATH»*, и запустите снова. |
| **macOS** | Дважды щёлкните **`START_OKO.command`**. Если система не даёт открыть: правый щелчок → «Открыть». |
| **Linux** | `./start_oko.sh` или `python3 oko.py` |

Откроется браузер с адресом `http://127.0.0.1:8765/`. Окно с чёрной консолью — это сервер ОКО: не закрывайте его, пока работаете. По умолчанию сервер доступен только на вашем компьютере.

При первом запуске ОКО в фоне проверяет сайты реестра и находит их RSS-ленты и поиск по сайту. Это занимает несколько минут и повторяется раз в неделю. Поиском можно пользоваться сразу.

> Если открыть `web/index.html` двойным щелчком без запуска сервера, ОКО работает в **автономном режиме**: доступны только GDELT и OpenAlex, без проверки первоисточников, перевода и PDF.

## Поиск

Над строкой поиска — вкладки:

| Вкладка | Что делает |
|---|---|
| **Тематика** | Страна, регион, организация или явление (по умолчанию «Узбекистан»). Кнопки-направления — *Экономика, Энергетика, Безопасность, Внешняя политика, Инвестиции и торговля, Права человека, Вода и климат, Миграция, Выборы и реформы, Транспорт* — сужают выдачу: материал должен касаться темы **и** направления. Термины направлений заданы на всех языках поиска. |
| **Ключевые слова** | Любые слова через запятую (ИЛИ), поля **«и»** (должно быть также) и **«не»** (исключить), «точная фраза», поиск без перевода. |
| **Персоны** | Человек из Wikidata: должности, гражданство, официальные сайты и аккаунты, имя на всех языках. Затем — упоминания в СМИ и соцсетях. В заголовках обычно пишут только фамилию — ОКО это учитывает. |
| **OSINT** | Проверка e-mail, телефона, @имени, домена, ссылки или IP по открытым данным: DNS, RDAP (WHOIS), публичные профили, веб-архив, упоминания в поисковиках. Без утечек баз и «пробива». |
| **Доклады** | Новые выпуски глобальных докладов и индексов за период + календарь: какие доклады ожидаются в этом и следующем месяце. |

Под строкой — период (**Сегодня · 24 ч · 3 дня · Неделя · Месяц · свои даты**) и свёрнутые **«Параметры»**: языки, термины по языкам, аналитика или широкий охват, уровень, категории источников, каналы поиска.

В выдачу попадает **только** заданный период: каждый материал проверяется по дате публикации.

### Лента результатов

- Переключатель **Материалы / Соцсети** — СМИ и аналитика отдельно от соцсетей.
- **Строго по теме** (включено) — только материалы, где тема есть в заголовке или аннотации либо подтверждена проверкой страницы. Скрытые показываются одной кнопкой.
- Фильтры слева сворачиваются: уровень, статус, **найдено по ключевому слову**, **соответствие теме**, тип источника, страна, язык, издание, доступ, отметки.
- Строки компактные: аннотация раскрывается стрелкой ▸. В меню **«Вид»** — сортировка, группировка (лента, сюжеты, по уровням, по источникам), аннотации, **заголовки по-русски**.
- Метка **⌕** у материала — сработавший термин; голубая — связанный термин (столица, президент, город).

### Карточка материала

Разделы сворачиваются, открытые запоминаются:

1. **Найдено по** — ключевое слово, сработавший термин и откуда он (перевод из словаря ОКО, Wikidata, машинный перевод, связанный термин, добавлен вручную), где найден, соответствие теме, цитата со страницы, запрос.
2. **Статус** — первоисточник / перепубликация / не определено с обоснованием; «Проверить первоисточник».
3. **Перевод на русский** — заголовок и аннотация сразу; «Перевести полный текст», «Читать в переводе», «PDF перевода».
4. **Сведения** — издание, авторы, дата, уровень; «Все сведения» — остальное.
5. Аннотация, сюжет (кто опубликовал первым), связанные публикации, действия (PDF, веб-архив), заметка.

Кнопки: **Оригинал · Ссылка · Цитата (ГОСТ) · В досье · Следить за источником**.

### Мониторинг источников

Отметьте источники значком **«глаз»** в разделе «Источники», кнопкой **«Следить за источником»** в карточке или через **«+ Добавить источник или канал»** в «Мониторинге» — там же добавляются Telegram-каналы. **«Обновить»** показывает последние публикации всех выбранных источников за 24 часа, 3 дня или неделю, по источникам, с отметкой новых. Необязательный фильтр отбирает публикации по слову.

**Досье** — избранные материалы с заметками; из досье формируется PDF-сводка и CSV.

**Архив** — каждый поиск сохраняется автоматически; прошлые результаты открываются без повторного запроса.

## Как ОКО определяет уровень, статус и соответствие

**Уровень авторитетности** берётся из реестра, его можно менять в разделе «Источники»:

| | Уровень | Кто входит |
|---|---|---|
| **A** | высший | Ведущие аналитические центры мира (Chatham House, IISS, RUSI, Carnegie, CSIS, Brookings, RAND, CFR, Atlantic Council, SWP, IFRI, ECFR, Crisis Group…), международные организации (ООН, ВБ, МВФ, АБР, ЕБРР, ОБСЕ, ШОС, ОТГ…), официальные источники, Reuters, AP, AFP, Bloomberg, FT, WSJ, NYT, Economist, Le Monde, Nikkei, рейтинги и индексы |
| **B** | высокий | Национальные аналитические центры и качественные издания, национальные агентства (государственные — с пометкой «гос.»), профильные издания по Центральной Азии |
| **C** | базовый | Прочие известные СМИ |
| **D** | вне реестра | Найдено в широком поиске; официальные домены (`.gov`, `.int`, `.gouv.fr`…) распознаются автоматически |

**Статус информации:**

- ✔ **Первоисточник** — собственный материал организации или издания либо самая ранняя из совпадающих публикаций.
- ⟳ **Перепубликация** — ссылка на другое издание («сообщает Reuters», «(AFP)», «— ТАСС», «据新华社»…), совпадение с более ранней публикацией, агрегатор, пересланный пост в Telegram или репост VK, либо страница указывает первоисточник (`rel=canonical`, `original-source`).
- **?** **Не определено** — признаков недостаточно.

**Соответствие теме:** ключевое слово в заголовке → связанный термин в заголовке → ключевое слово в аннотации → тема в тексте статьи (проверено: 2+ абзаца или начало статьи) → упоминание вскользь → не найдено на странице → только по данным поисковика (не проверено). Режим «Строго по теме» показывает первые четыре уровня и проверенные.

Всё это — автоматическая оценка с обоснованием: ключевые материалы сверяйте по оригиналу.

## Каналы сбора

| Канал | Что даёт | Ограничения |
|---|---|---|
| Google News | Издания ~20 стран на 15 языках, точный период, адресный поиск по сайтам аналитических центров (`site:`, сначала уровень A) | ≤100 материалов на запрос — длинный период ОКО делит на части; лимит 120 запросов на поиск (настраивается) |
| GDELT | Мировые СМИ на 65 языках, страна издания | Только последние ~3 месяца; 1 запрос в 5 секунд |
| RSS-ленты реестра | Свежие публикации аналитических центров и изданий напрямую | Лента хранит только последние материалы |
| Поиск по сайтам (WordPress API) | Полнотекстовый поиск на сайтах аналитических центров | Только сайты на WordPress |
| Bing News | Дополнительный охват | Около месяца |
| OpenAlex · Всемирный банк · GOV.UK · ReliefWeb | Наука, доклады и документы, официальные публикации | ReliefWeb — нужен бесплатный `appname` |
| Доклады | Выпуски ~80 флагманских докладов и индексов | — |
| Telegram | Публичные каналы (поиск внутри канала), без ключей | Закрытые каналы недоступны; глобального веб-поиска по Telegram нет |
| ВКонтакте · X · YouTube | Поиск публикаций по API | Нужны ключи; поиск X — платный API, 7 дней |
| LinkedIn · Facebook · Instagram · WhatsApp-каналы | Публичные публикации через поисковик (Brave Search или Google Programmable Search) | Нужен бесплатный ключ; видно только проиндексированное |

Подробно о соцсетях, ключах, Telegram-боте и телефоне — **[docs/MOBILE_AND_SOCIAL.md](docs/MOBILE_AND_SOCIAL.md)**.

### Ошибки каналов

Счётчик **«Ошибок»** и **«Журнал»** показывают, какой канал не ответил, причину («сайт запрещает автоматические запросы», «адрес ленты больше не существует», «сайт не отвечает или недоступен из вашей сети»…), что делать и адрес запроса. Кнопка **«Скопировать отчёт об ошибках»** — чтобы переслать список разработчику.

ОКО само восстанавливается:

- канал, который падает несколько поисков подряд, отключается на 12 → 24 → 48 → 72 часа и затем проверяется снова (список — «Источники → Каналы с ошибками», там же «Проверить снова»);
- если Google News, GDELT или Bing ограничили частоту запросов, сервис ставится на паузу, оставшиеся запросы помечаются «пропущено» (а не ошибкой) — повторите поиск через 10–15 минут;
- исчезнувшую RSS-ленту ОКО ищет на сайте заново; случайный таймаут ленту не «портит»;
- сайтам с неполной цепочкой SSL-сертификатов (часто у госсайтов) ОКО, как браузер, дозагружает промежуточный сертификат — с полной проверкой до корневого сертификата системы.

## PDF, перевод и сохранение

- **PDF оригинала** — через установленный Chrome, Edge, Яндекс.Браузер или Brave в папку `pdf/`.
- **PDF (режим чтения)** — чистый текст статьи с таблицей метаданных; **PDF перевода** — то же на русском.
- **Экспорт:** CSV для Excel, HTML-отчёт, JSON, PDF-сводка (с колонками «Найдено по» и «Соответствие»).
- **Веб-архив:** сохранение копии в Wayback Machine или archive.today.
- **Перевод:** Google Переводчик без ключа; для лучшего качества — ключ DeepL (бесплатный тариф) в настройках.

## Если что-то не работает

- **«Нет связи с сервером ОКО»** — окно-консоль закрыто. Запустите ОКО снова.
- **Много ошибок в журнале** — нажмите «Скопировать отчёт об ошибках» и пришлите текст разработчику. Сайты, заблокированные у вашего провайдера, открываются через VPN.
- **macOS: ошибка SSL-сертификата** — выполните `Applications → Python 3.x → Install Certificates.command`.
- **Google News: «ограничил частоту запросов»** — ОКО делает паузу на 10 минут, остальные каналы работают. Можно уменьшить лимит запросов в «Настройках».
- **Корпоративная сеть с прокси** — ОКО учитывает переменные `HTTPS_PROXY` / `HTTP_PROXY`.
- **PDF оригинала не создаётся** — нужен Chrome, Edge или другой браузер на Chromium. Путь можно задать переменной `OKO_CHROME`. Без браузера используйте «Режим чтения → Печать».
- **Другой порт:** `python oko.py --port 9000`. Без автозапуска браузера: `--no-browser`. Доступ с телефона: `--lan`.
