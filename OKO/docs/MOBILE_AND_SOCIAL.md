# ОКО: соцсети и телефон

## 1. Соцсети

Результаты из соцсетей показываются **отдельно** — переключатель **«Материалы / Соцсети»** над лентой. В разделе «Соцсети» есть фильтр по платформам и кнопки «Искать на платформе». Эти кнопки открывают поиск на самой платформе в вашем браузере, где вы уже вошли в аккаунт.

| Платформа | Как ищет ОКО | Что нужно |
|---|---|---|
| **Telegram** | Публичные каналы: поиск по теме внутри каждого канала через веб-версию `t.me/s/<канал>`. Пересланный пост помечается как перепубликация с указанием канала-первоисточника. | Ничего. Список каналов — «Настройки → Соцсети и ключи API», можно добавить свои. |
| **ВКонтакте** | Поиск по открытым записям (`newsfeed.search`), репост — перепубликация. | Сервисный ключ приложения VK. |
| **X (Twitter)** | Поиск за последние 7 дней (API v2), без ретвитов. | Bearer Token. Поиск доступен только в платных тарифах API X. |
| **LinkedIn, Facebook, Instagram, X, VK, Telegram, WhatsApp-каналы** | Публичные публикации, которые проиндексировали поисковые системы: запрос `(Uzbekistan OR Узбекистан) site:linkedin.com …`. | Бесплатный ключ **Brave Search API** или **Google Programmable Search** (ключ + cx). |
| **YouTube** | Видео за период (YouTube Data API). | Бесплатный ключ Google. |

### Где взять ключи

- **Brave Search API** (рекомендуется для LinkedIn, Facebook, Instagram, WhatsApp-каналов): зарегистрируйтесь на `api-dashboard.search.brave.com` и выберите бесплатный тариф (около 2000 запросов в месяц). Скопируйте ключ в поле «Brave Search API: ключ».
- **Google Programmable Search** (альтернатива Brave):
  1. На `programmablesearchengine.google.com` создайте поисковую систему с опцией «Поиск во всём интернете» и скопируйте её идентификатор **cx**.
  2. В `console.cloud.google.com` включите **Custom Search API** и создайте ключ.
  3. Бесплатно — 100 запросов в день.
- **ВКонтакте:** на `dev.vk.com` откройте «Мои приложения» и создайте приложение. Затем скопируйте «Сервисный ключ доступа».
- **YouTube:** в `console.cloud.google.com` включите **YouTube Data API v3** и создайте ключ.
- **X:** ключ Bearer Token выдаётся на `developer.x.com`. Поиск по API — платная функция.
- **DeepL** (необязательно, для качественного перевода): бесплатный ключ на `deepl.com/pro-api`. Ключ бесплатного тарифа оканчивается на `:fx`.

Ключи хранятся только на вашем компьютере, в файле `data/state/settings.json`. В интерфейсе они скрыты маской.

### Что невозможно и почему

- **WhatsApp:** переписка зашифрована, поиска по сообщениям не существует ни у кого. Видны только публичные **каналы** WhatsApp, которые проиндексировали поисковые системы. Их ОКО ищет через Brave или Google.
- **Facebook и Instagram:** Meta закрыла поиск публикаций через API для сторонних приложений. Доступно только то, что проиндексировали поисковые системы, плюс ручной поиск кнопкой «Искать на платформе».
- **Глобальный поиск по всему Telegram:** есть только в приложении Telegram, потому что требует входа в аккаунт. ОКО ищет по публичным каналам из списка. Каналы по теме удобно подбирать через TGStat — кнопка «Telegram» в разделе «Соцсети».
- **Закрытые группы, личные страницы и сообщения** ОКО не собирает.

## 2. Telegram-бот

Бот работает внутри запущенного ОКО и отвечает только вам.

1. В Telegram найдите **@BotFather** и отправьте `/newbot`. Придумайте имя и получите **токен**.
2. В ОКО откройте «Настройки → Телефон: Telegram-бот и доступ из браузера» и вставьте токен. Нажмите «Сохранить».
3. Напишите своему боту `/start`. Он ответит вашим **Telegram ID**.
4. Впишите этот ID в поле «Разрешённые Telegram ID» и сохраните. Можно указать несколько ID через запятую.

Команды:

| Команда | Что делает |
|---|---|
| тема (например, `Узбекистан`) или `/search тема` | Самые авторитетные материалы за 24 часа, строго по теме, с меткой «⌕ по какому слову найдено». Полная сводка приходит HTML-файлом. |
| `/today [тема]` | Материалы за сегодня |
| `/week [тема]` | Материалы за 7 дней |
| `/watch` | Новые публикации источников из «Мониторинга» |
| `/reports` | Новые глобальные доклады и индексы за неделю |
| `/digest 08:30 [тема]` | Ежедневная сводка в указанное время; `/digest off` — отключить |
| `/status` | Состояние ОКО |

Бот работает, пока запущено ОКО: на компьютере или на телефоне через Termux (см. раздел 4). Чтобы сводки приходили каждое утро, компьютер с ОКО должен быть включён.

## 3. ОКО в браузере телефона (домашняя сеть)

1. В «Настройки → Телефон» задайте **пароль доступа** — не короче 8 символов.
2. Запустите ОКО командой `python oko.py --lan`. Можно добавить `--lan` в `START_OKO.bat` после `oko.py`.
3. В окне ОКО появится адрес вида `http://192.168.1.25:8765/`. Откройте его в браузере телефона, подключённого к **той же Wi-Fi-сети**, и введите пароль.
4. В меню браузера выберите «Добавить на главный экран»: ОКО откроется как отдельное приложение со своим значком.

Безопасность:

- Вход только по паролю; после 5 ошибок за 5 минут вход блокируется.
- Сервер принимает запросы только по IP-адресу домашней сети. Это защита от подмены DNS.
- Соединение идёт по HTTP внутри домашней сети. **Не открывайте этот порт в интернет.** Для доступа вне дома используйте Telegram-бота или личный VPN до домашней сети (WireGuard, Tailscale).

## 4. Android без компьютера (Termux)

ОКО написано на Python без сторонних библиотек, поэтому запускается прямо на телефоне Android.

1. Установите **Termux** из F-Droid. Версия из Google Play устарела.
2. В Termux выполните:
   ```
   pkg update && pkg install python git
   git clone https://github.com/homopoliticuz/OSINT-tool oko && cd oko/OKO
   python oko.py --no-browser
   ```
   Если репозиторий закрытый, проще скопировать архив ОКО во внутреннюю память телефона. Затем выполните `termux-setup-storage`, распакуйте архив (`unzip ~/storage/downloads/OKO.zip`) и перейдите в папку командой `cd OKO`.
3. Откройте в браузере телефона `http://127.0.0.1:8765/`.
4. Чтобы Android не останавливал ОКО в фоне, выполните `termux-wake-lock`. Бот при этом тоже работает.

PDF оригинала на телефоне недоступен: нужен настольный Chrome. Используйте «Режим чтения» и печать из браузера («Сохранить как PDF»).

## 5. Про APK

Отдельное APK-приложение не собирается: ОКО — это локальный сервер плюс веб-интерфейс. Для телефона есть три готовых варианта:

- **Telegram-бот** — быстрые сводки и поиск откуда угодно.
- **Браузер телефона** в домашней сети — полный интерфейс, можно «установить» на главный экран.
- **Termux** — ОКО целиком на Android, без компьютера.

Нативное APK потребовало бы отдельной сборки (Python внутри Android-приложения через Chaquopy или BeeWare) и не добавило бы новых возможностей. На iPhone используйте бота или браузер в домашней сети.
